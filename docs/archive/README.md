# `docs/archive/` — Arquivo Histórico / Historical Archive

Este diretório preserva documentos históricos, planos de desenvolvimento e especificações da era original da aplicação desktop (**Avalonia UI**), que foi descontinuada e substituída pela extensão nativa do Visual Studio Code na fase **F6** (Setembro de 2026).

> [!NOTE]
> Esses arquivos são mantidos exclusivamente como registro histórico de decisões de arquitetura e evolução da base de código. Eles **não** são atualizados com as versões mais recentes do software.
